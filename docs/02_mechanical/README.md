# 02 機械設計

Autodesk Fusion による CAD 設計と 3D プリント部品の設計記録。

- 全体構成と寸法
- 地形に合わせた形状最適化（脚長・股関節配置・胴体寸法の評価、[RoboGrammar](../references/robogrammar.md) を参考）
- 脚部（股関節、大腿・下腿リンク、膝関節、ベアリング、足裏）
- 胴体（バッテリー・計算機・センサ搭載、放熱）
- 屋外対応（防塵・防滴、転倒対策、ケーブル保護）
- 3D プリント条件（材料、積層方向、インフィル、ねじ固定）

CAD データ本体は `hardware/` などリポジトリ側で管理し、ここには設計判断と図面の説明を置く。

関連: [design.md §6](../../design.md)（形状最適化は §6.3）
