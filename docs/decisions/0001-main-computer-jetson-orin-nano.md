# 0001 メイン計算機に Jetson Orin Nano を採用する

- 日付: 2026-11-24
- 状態: 採用

## 背景

メイン計算機は「Raspberry Pi 5 / NVIDIA Jetson」の 2 案のまま決まっていなかった。胴体の搭載スペース、電源系、放熱、ソフトウェア環境はどれも計算機に左右されるため、Phase 1 の設計に入る前に決める必要がある。

Phase 5〜6 では、計算機が次の処理を同時に受け持つ。

- 3D LiDAR と RGB-D カメラの入力処理
- 屋外 SLAM と Nav2
- RL 歩行ポリシーの推論
- VLA（SmolVLA など）の実機推論

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| Raspberry Pi 5 | 安い。Pupper v3 と同じ系統で資料が多い | GPU がなく、VLA の推論や SLAM との同時処理には力不足 |
| Jetson Nano（初代） | 安価な GPU 搭載ボード | 公式環境は Ubuntu 18.04（JetPack 4）止まりで、ROS 2 Humble / Jazzy を素直に使えない |
| **Jetson Orin Nano** | GPU があり、VLA・認識・RL の推論を 1 台で回せる。JetPack 6（Ubuntu 22.04）で ROS 2 Humble が使える | Pi 5 より高価で、消費電力と発熱が大きい |
| Pi 5 で始めて後から Jetson に載せ替え | 初期費用が安い | 胴体・電源・ソフトウェアを 2 回作ることになる |

## 決定

メイン計算機は **NVIDIA Jetson Orin Nano** とする。Phase 1 から使う。

関節モータの低レベル制御を担うマイコン（STM32 / ESP32）は、この決定の対象外とし、アクチュエータの選定と合わせて別途決める。

## 理由

- Phase 5〜6 の処理を 1 台でまかなえる計算資源を、最初から確保できる。
- 計算機を途中で載せ替えないので、胴体・電源・放熱の設計が 1 回で済む。
- 開発の初期から実機と同じ環境（JetPack / CUDA / ROS 2）で検証でき、Sim2Real や VLA の移行で環境の違いに悩まずに済む。

## 影響

- **機構**: 胴体に Jetson Orin Nano のモジュールとキャリアボード、ヒートシンク・ファンを収める。吸排気の経路を確保し、屋外での防塵・防滴と両立させる。
- **電源**: 最大 25 W 程度の消費を見込んで電源系を設計する。モータ電源とは系統を分け、電圧降下やノイズで計算機が落ちないようにする。
- **ソフトウェア**: JetPack 6（Ubuntu 22.04）+ ROS 2 Humble を基本環境とする。
- **予算**: 計算機の費用は 4 万〜6 万円程度を見込む（キャリアボード・ストレージ込み、為替で変動）。
- **Pupper v3 との違い**: Pupper v3 は Raspberry Pi 系なので、Pupper のソフトウェアを参考にする場合は Jetson 向けに移植・確認が要る。
